# Modded Item Upgrader 0.9.0

Unified update for all nine supported Minecraft/loader editions.

## Interface

- Refreshed charcoal/champagne styling, clearer panels, selection and status.
- Move the wheel marker by dragging around the circle, or use its rotation/reset controls. Position is saved locally and never changes the server-authoritative outcome.
- 1.5×, 2×, 5× and 10× shortcuts beneath the reward select the closest feasible reward stack. They do not start a roll. Actual values and chance remain visible, including when an exact multiplier is impossible.
- After a roll, the wheel previews the next attempt's current chance while the previous outcome remains in its result message. Moving the marker clears the finished wheel animation.

## Catalog and balance

- Complete missing ordinary item registry entries with conservative fallback pricing after normal recipe, acquisition and attribute evaluation.
- Keep calibrated reward prices intact; limit estimated stake values and propagate those limits through supported recipes to prevent value inflation.
- Include pristine fluid containers while retaining validation of custom item contents.
- Preserve expensive crafted block prices instead of overwriting them with cheap hardness estimates.
- Correct filled bucket prices relative to the empty bucket, and strengthen rare vanilla reward pricing.
- Account for recipe containers returned after crafting; propagate net consumable costs to stake values and correct vanilla cake pricing without counting returned buckets as consumed ingredients.
- Price vanilla world conversions coherently: concrete hydration, copper weathering, pumpkin carving, melon drops, moss, nylium and bucket collection. Coloured eggs inherit ordinary egg pricing in Minecraft 26.3. Stake values account for returned containers and maximum byproduct yields.
- Apply these changes to the legacy releases and the current Minecraft 26.3 ports.

Operator-only items, spawn eggs, explicit exclusions and unsafe recipe cycles remain unavailable. Registry coverage does not mean every possible custom NBT/component variant or every third-party machine is understood. Use `/upgrade audit` and datapack profiles to inspect and tune modpack-specific values.

## Installation

Install the exact 0.9.0 edition on client and server. Fabric needs the matching Fabric API. Java 17: Minecraft 1.19.2/1.20.1; Java 21: 1.21/1.21.1; Java 25: 26.3. NeoForge 26.3.0.48-beta is a beta loader.

The chance formula is unchanged. Existing inventory items and accepted delayed payouts keep their normal server-side handling.

## Design references

The interface emphasizes visible state, clear feedback and user-controlled selection, following [Nielsen Norman Group's visibility-of-status guidance](https://www.nngroup.com/articles/visibility-system-status/). Multiplier shortcuts preview a choice; the final roll remains an explicit action.
