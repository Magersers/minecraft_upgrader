# Upgrader Fabric 0.6.0-alpha — характеристики, материалы и износ

Розовые лепестки стоят **1 E за штуку**, а не 279 E по редкому сундуку. В чтении генерации исправлен контекст реестров: естественные цветы распознаются и без индивидуальной цены. Эти цены — правила игрового баланса, а не объективное измерение редкости.

## Новая оценка

- Мечи и инструменты: фактические атрибуты урона и скорости атаки, максимальная прочность, скорость добычи. Ориентир — алмазный меч (7 урона, 1.6 атаки/с, 1561 прочности, около 240.5 E) и алмазная кирка (361 E). Урон × скорость возводятся в степень 1.6; долговечность растёт с показателем 0.35, поэтому одна огромная прочность не перевешивает всё остальное.
- Броня: защита, твёрдость, прочность относительно алмазной детали того же слота; дополнительные здоровье, сопротивление отбрасыванию, скорость и дальность взаимодействия. Цена по характеристикам заменяет цену крафта снаряжения и распространяется в последующие рецепты.
- Для луков/арбалетов используется базовая оценка класса и прочности: произвольные модовые снаряды этим не анализируются. Модификации Tinkers со специальными данными по-прежнему требуют своего адаптера; существующий расчёт материала сохранён.
- Неизвестные материалы оцениваются обратно из цены готового снаряжения. Из бюджета вычитаются известные ингредиенты; остаток поровну делится между **видами** неизвестных материалов, затем на их количества. Сапоги 200 E из 4 слитков → 50 E/слиток. Из 4 слитков и 1 кристалла, когда оба неизвестны → 25 E/слиток и 100 E/кристалл. Известная цена слитка 30 E → кристалл 80 E. Альтернативные теги без однозначного материала не угадываются. Из нескольких оценок одного материала выбирается большая; дешёвый декоративный блок не служит основанием обратного расчёта дорогого универсального материала. Обратный обход ограничен 16 уровнями и не возвращается к уже оценённым узлам.
- Простой строительный блок, не используемый ингредиентом импортированных рецептов: `1 + твёрдость^1.5`. Функциональные блоки с хранилищем/меню/сигналом исключены из этой эвристики; одного отсутствия рецепта недостаточно, чтобы считать любую модовую машину декором.
- Кузнечные шаблоны: учитывается добыча из загруженных сундуков и **стоимость одной дополнительной копии**, не половина стоимости рецепта с расходуемым шаблоном. Выбирается большая оценка. Для незеритового шаблона базовая копия: 7 алмазов + незерак = 841 E. Этапы доступа сохраняются.

## Износ и хард-режим

Изношенные обычные инструменты и броню можно выбирать в инвентаре. Цена ставки = цена нового × `max(0.01, 1 − износ / максимальная прочность)`. Почти сломанный предмет теряет до **99%** цены. Имена, произвольные модификаторы и содержимое не удаляются при проверке; предметы с неподдерживаемыми данными не становятся доступными обходным путём.

`/upgrade hard true` включает режим, `/upgrade hard false` выключает (права оператора). Камень, земля, дерево, лепестки и распознанный простой декор дают максимум **0.5 E/шт. как ставка**. Цена получения этих предметов остаётся обычной. Настройки сохраняются в `config/upgrade-economy.json`; `simple_stake_cap` можно задать в интервале `(0, 1]`. По умолчанию хард-режим выключен. В подсказках разделены «Цена ставки» и «Цена получения».

## Способности и энергия

Надбавки задаются в datapack `data/<namespace>/upgrade_abilities/*.json`. Встроены элитры, черепаший шлем и профили нано-/квантовой брони TechReborn для Fabric. Поддерживается чтение заряда через Fabric Energy API, без расходования энергии. Заряженные надбавки пропорциональны доле заряда: 1 единица энергии не оценивается как полная батарея. Профили TechReborn учитывают щит, дыхание, ночное зрение, полёт, тушение огня и ускорение; настройки отключения полёта/спринта в TechReborn проверяются.

Пример профиля для известного меча с ядом:

```json
{"items":[{"item":"example:venom_sword","abilities":[{"type":"poison","strength":1}]}]}
```

Типы и надбавки за `strength: 1`: `flight` 12000 E, `gliding` 6000, `double_jump` 1500, `water_breathing` 600, `night_vision` 250, `poison` 1200, `wither` 2400, `regeneration` 3000, `fire_immunity` 1800, `fire_extinguish` 600, `shield` 120 за условную единицу защиты, `speed` 800. `charged: true` связывает надбавку с зарядом. Множитель `strength` позволяет задавать намного более высокую ценность. Это явные настройки баланса, а не доказанная эквивалентность способностей.

Произвольный эффект из Java-кода другого мода **не распознаётся универсально**. Нельзя надёжно понять двойной прыжок или яд из одного названия/описания предмета. Для таких случаев нужен профиль либо адаптер, который читает контракт мода. Неизвестные эффекты отмечаются в объяснении цены. Автоматическое выполнение боевых/тиковых методов для «пробного» анализа не используется. IndustrialCraft для Forge здесь не запускается; энергетическая интеграция проверена на TechReborn 5.8.8 + RebornCore 5.8.8 + Energy 3.0.0 для Minecraft 1.20.1. Другие версии энергетических модов требуют отдельной проверки.

Источники контрактов: [Fabric Energy API](https://github.com/TechReborn/Energy/blob/3.x/src/main/java/team/reborn/energy/api/base/SimpleEnergyItem.java), [QuantumSuitItem](https://github.com/TechReborn/TechReborn/blob/1.20/src/main/java/techreborn/items/armor/QuantumSuitItem.java), [NanoSuitItem](https://github.com/TechReborn/TechReborn/blob/1.20/src/main/java/techreborn/items/armor/NanoSuitItem.java).

## Проверки

Серверные тесты проверяют цену лепестков при конфликтующем сундуке 279.27 E, реальное чтение генерации, характеристики алмазного/незеритового оружия, распределение 4 слитков + кристалла, циклы обратного расчёта, надбавку яда, износ 50% и 99%, сохранение хард-режима и серверную цену награды. Отдельно проверены реальные энергетические предметы TechReborn при 0, 1, половине и полном заряде. Профиль TechReborn зафиксирован в `fabric/test-mods/techreborn-1.20.1.json` с проверкой SHA-512.

## Установка

Замените старый JAR на клиенте и сервере и перезапустите игру. Используйте файл строго для своей версии:

- Minecraft 1.20.1: Java 17+, Fabric Loader 0.17.2+, Fabric API 0.92.12+1.20.1.
- Minecraft 1.21.1: Java 21+, Fabric Loader 0.17.2+, Fabric API 0.116.17+1.21.1.

Forge-релиз сохранён отдельно. Полная сборка BMC2 здесь не считается автоматически проверенной. `/upgrade audit` создаёт `logs/upgrade-economy.json` с неизвестными/исключёнными предметами и объяснениями цен.
