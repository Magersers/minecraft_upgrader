# Upgrader Fabric 0.6.2-alpha — компактные подсказки

В инвентаре апгрейдера, каталоге и карточках ставки/награды подсказки стали короче:

- Выделенное название предмета и название его мода из Fabric Loader.
- Урон, броня и твёрдость, если предмет предоставляет соответствующие атрибуты. Числа относятся к самому предмету, без эффектов игрока и ситуативных бонусов.
- Только итоговая ценность за 1 предмет: отдельно подписаны ставка и награда. Числа имеют разделители тысяч и не содержат лишних нулей.
- Мягкие цветные акценты: урон — коралловый, защита — голубой, ценность — золотая.

Убраны технические ID предметов, формулы, рецепты и длинные объяснения оценки. Подробности расчёта остаются в `/upgrade audit`. Для закрытых целей выводится короткое «Пока недоступно». Баланс 0.6.1 сохранён.

Сборки: Fabric 1.20.1 (Java 17+) и 1.21.1 (Java 21+), Fabric Loader 0.17.2+. Замените предыдущий JAR на клиенте и сервере. Отдельный Forge-релиз сохранён.
