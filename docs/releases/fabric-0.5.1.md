# Upgrader Fabric 0.5.1-alpha — наследование цен модовых предметов

Выбирайте файл строго под Minecraft: `upgrade-fabric-1.20.1-0.5.1-alpha.jar` (Java 17+) или `upgrade-fabric-1.21.1-0.5.1-alpha.jar` (Java 21+). Нужен Fabric Loader 0.17.2+ и Fabric API 0.92.12+1.20.1 / 0.116.17+1.21.1 соответственно. Замените старый Upgrader на клиенте и сервере.

Исправление 0.5.1: сложные пулы лута с группами/альтернативами больше не могут искажать вероятность соседних обычных предметов. Такой пул оставляется для отдельного профиля.

## Что изменилось

Ранее неизвестный базовый ресурс оставлял без цены всю цепочку его крафтов. Теперь расчёт дополняет граф источниками из загруженной генерации мира, семейств природных блоков, фактического дропа блоков, мобов и сундуков. Цена проходит через всю цепочку с учётом количества ингредиентов и выхода. Поддерживается и программный дроп без JSON-таблицы.

Добавлены сплавы и ковка BCLib, инфузия BetterEnd со всеми катализаторами и импорт простых модовых рецептов с одними предметами. Нераспознанные требования жидкостей, энергии, количественных ингредиентов и особых данных не отбрасываются молча: нужен адаптер/профиль.

Исправлена отдельная ошибка базовых тегов: нахождение цинцинназита в группе железных слитков для крафта больше не назначает ему цену железа. Теги выбирают альтернативные ингредиенты; автоматическая базовая цена не приравнивает все материалы группы.

Сложность модового моба влияет через HP, броню, атаку и ожидаемый дроп. Явные профили боссов сохраняют приоритет перед автоматическими источниками. Приблизительные оценки помечены в подсказке; они являются моделью баланса, а не измеренной редкостью. Коэффициент доверия 0.85 — политика допуска, а не статистическая точность 85%.

## Проверка покрытия

На отдельном сервере **1.20.1 с BetterEnd 4.0.11, BetterNether 9.0.10, BCLib 3.0.14 и WunderLib 1.1.5**:

| Мод | Оценено | Пока неизвестно | Исключено |
|---|---:|---:|---:|
| BetterEnd | 757 | 28 | 19 |
| BetterNether | 533 | 50 | 21 |

Это проверка этих модов, **не полного BMC2**: конфиги, датапаки и остальные моды сборки могут менять результаты. «Оценено» не означает, что уже выполнены нужные достижения. Автоматические источники BetterEnd требуют входа в Край, BetterNether — входа в Незер; требования наследуются крафтами.

Проверены цепочки талласия, терминита, аэтерниума, цинцинназита и зачарованного лепестка; вес неподдерживаемого зачарованного лута не искажает вероятность остальных предметов; скрытые требования не превращаются в бесплатные ингредиенты. Обе сборки проходят тесты ядра и выделенного сервера, включая пачки, задержку выдачи, сохранение выигрыша и отклонение поддельных запросов.

Также повторно проверен Hephaestus 3.6.4.279 с Mantle 1.9.269 / Porting Lib 2.3.4: материалы, жидкости, новый составной инструмент и отклонение изменённых предметов; 2090 записей цены вместе с внутренними узлами.

## Настройка и диагностика

Команда администратора `/upgrade audit` пишет `logs/upgrade-economy.json`: цены, требования, объяснения и отдельные счётчики неизвестных/исключённых предметов по каждому моду. Во вкладке «Все» остаются видны причины недоступности.

Датапак может заменить `data/upgrade/upgrade_inheritance/policy.json`: отключить автоматические источники, отдельные типы добычи, настроить бюджет поиска сундуков/мобов и требования измерений по namespace. Цены отдельных ресурсов и машин задаются через `upgrade_values`, сложность боссов — через `upgrade_encounters`. После изменений выполните `/reload`.

Для руд BetterX средний выход берётся из их фактических min/max; для остальных таблиц блоков используются 128 проб с фиксированными seed. Произвольные переопределения дропа в коде мода могут использовать собственный RNG, поэтому их оценки могут немного изменяться при пересчёте. Скрытые фазы боссов, скриптовые квесты, контекстный лут и NBT-варианты требуют отдельных правил; универсальная точная цена для них не заявлена.

Инвентарь, поиск по названиям, выбор количества награды, стрелка, звуки и выдача после прокрутки сохранены. [Forge 1.20.1 остаётся в отдельном релизе 0.3.0-alpha](https://github.com/Magersers/minecraft_upgrader/releases/tag/forge-1.20.1-v0.3.0-alpha).
