# Modded Item Upgrader 0.6.4-alpha

Publication package for Fabric 1.20.1 and 1.21.1. Includes the recipe-consistent economy from 0.6.3 and compact item tooltips from 0.6.2.

- Author metadata now credits Magersers.
- New releases carry the Magersers Proprietary License (All Rights Reserved), included in the JAR; earlier license grants remain unaffected.
- Added an original AI-generated promotional icon and bilingual project descriptions.
- Preserved the Forge MDK third-party notice separately; historical Forge releases remain unchanged.
- Updated demonstration screenshots to the current economy.

Install the matching Fabric JAR on both client and server with the required Fabric API. Java 17+ for Minecraft 1.20.1, Java 21+ for 1.21.1. The interface is primarily Russian. This is an alpha; complete Better MC BMC2 compatibility is not claimed.

Код, оформление подсказок и баланс предыдущей версии сохранены. Добавлены авторство Magersers, закрытая лицензия для новых выпусков, иконка и материалы для публикации. Старые JAR не переименовываются и не заменяются.
