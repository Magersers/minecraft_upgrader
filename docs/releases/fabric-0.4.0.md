# Upgrader Fabric 0.4.0-alpha

Fabric-порт рулетки улучшения предметов. **Выбирайте JAR строго под версию Minecraft:**

| Minecraft | Файл | Java | Fabric API |
|---|---|---|---|
| 1.20.1 | `upgrade-fabric-1.20.1-0.4.0-alpha.jar` | 17+ | 0.92.12+1.20.1 или новее для 1.20.1 |
| 1.21.1 | `upgrade-fabric-1.21.1-0.4.0-alpha.jar` | 21+ | 0.116.17+1.21.1 или новее для 1.21.1 |

Нужен **Fabric Loader 0.17.2+**. Установите Fabric API и один соответствующий JAR Upgrader в `mods` на клиенте и сервере. Удалите предыдущий Upgrader. Версии 1.20.2–1.20.6, 1.21.2+ и старше 1.20 пока не поддерживаются этими файлами.

## Возможности

- Выбор ставки из инвентаря, хотбара и второй руки: 37 слотов.
- Выбор количества ставки и получаемых предметов; цена всей пачки определяет шанс. Для нестакаемых предметов — одна штука.
- Рулетка с треугольной стрелкой, звуками, победой/поражением и выдачей выигрыша после прокрутки.
- Поиск по локализованным названиям и ID, вкладки, сортировка и объяснения стоимости.
- Расчёт цепочек крафта, альтернатив ингредиентов, количества выхода и настраиваемой сложности добычи.
- Отдельные адаптеры NBT/компонентов, сетевых пакетов, рецептов, тегов и интерфейса для двух версий Minecraft.
- Серверная проверка запросов, защита от повторной выдачи и сохранение ожидающего выигрыша в данных игрока.

Открытие — зелёная стрелка в обычном инвентаре или `/upgrade` в выживании. Сетевой протокол Fabric 4 требует одинаковой версии мода с обеих сторон.

## Совместимость и ограничения

Forge-моды нельзя запускать на Fabric. Для Tinkers’ Construct нужен Fabric-порт **Hephaestus для 1.20.1**; для остальных модов тоже нужны подходящие Fabric-сборки. Профили боссов Twilight Forest применяются только при наличии соответствующих сущностей и таблиц добычи. Проверка оригинальных Forge-версий Tinkers/TF не означает совместимость всех Fabric-портов.

**Проверен Hephaestus 3.6.4.279 + Mantle 1.9.269 + Porting Lib 2.3.4**: сплавы, материалы деталей, новый составной инструмент и отклонение изменённых инструментов. Более новые версии Hephaestus отдельно не проверены.

Специальные машины, контекстный лут, модифицированные инструменты и новые модовые форматы могут требовать профиля или адаптера. NBT-варианты деталей/инструментов используются как ставки, каталог наград содержит обычные предметы. Цены — настраиваемая модель баланса; это alpha-релиз.

## Проверки

При публикации обе версии проходят сборку, 10 145 проверок ядра и запуск выделенного сервера с проверками цены, выбранного слота, пачки награды, поддельных количеств, повторных запросов, задержки выдачи, сохранения данных игрока и чтения таблиц добычи. Интерфейс проверяется отдельно настоящим клиентом при 1280×800 и 640×480.
