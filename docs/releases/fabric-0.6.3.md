# Upgrader Fabric 0.6.3-alpha — согласованная экономика

Обычное снаряжение с известным рецептом больше не получает завышенную цену как доля от алмазного снаряжения. Его базовая ценность складывается из материалов рецепта с учётом количества выхода. Поэтому деревянный меч стоит 2.5 E, а не около 520 E. Для новых неповреждённых обычных вещей без особых данных в обычном режиме цена ставки и награды совпадает.

Сравнение усиленного снаряжения проводится с алмазным предметом того же типа/слота: топор с топором, кирка с киркой, нагрудник с нагрудником. Независимая оценка по характеристикам сохраняется для вещей без рассчитанного пути изготовления, вещей выше эталонного уровня, профилей способностей и поддержанной энергетической брони. Кубический рост за высокие боевые характеристики сохранён; эта надбавка не применяется к обычному слабому снаряжению. Антинакрутка ставок, износ и этапы доступа продолжают действовать.

## Полезные культуры и еда

Декоративные цветы/лепестки отделены от урожая, еды и полезных материалов. Обычные цветы остаются не дороже 1 E. Для кожи, чернил, тростника, зерна, овощей, мяса и рыбы установлены отдельные минимумы; модовые материалы наследуют поддержанные общие теги. Неизвестные исходные продукты могут получить минимум по питательности и насыщению, но готовые блюда наследуют стоимость ингредиентов вместо наценки за калории. Если старый источник готовой еды дешевле её известного крафта, приоритет получает рецепт; при неразрешимом рецепте сохраняется исходный источник.

Хард-режим больше не снижает полезный урожай и еду до стоимости декоративного мусора. Для простых камня, земли, дерева и декора ограничение ставки сохраняется. Цена награды хард-режимом не снижается.

## Примеры обмена и проверки

- Деревянный меч (2.5 E) → 64 тростника (512 E): **0.415%**.
- 14 обычных лепестков (14 E) → 5 алмазов (10000 E): **0.119%**.
- Доски → деревянное оружие не создают сотни единиц ценности.

Серверные проверки сравнивают реальные цены ставки и награды, суммы рецептов, износ, хард-режим, шансы пачек и сохранённые ограничения минеральных ресурсов. Моды могут добавлять альтернативные рецепты и тем самым менять итог; полная BMC2 отдельно не проверена. Компактные цветные подсказки 0.6.2 сохранены.

## Установка

Замените прежний JAR на клиенте и сервере и перезапустите игру/сервер. Fabric 1.20.1: Java 17+, Loader 0.17.2+, Fabric API 0.92.12+1.20.1. Fabric 1.21.1: Java 21+, Loader 0.17.2+, Fabric API 0.116.17+1.21.1. Настройка цен: `data/upgrade/upgrade_balance/policy.json`. Forge-релиз остаётся отдельным и неизменным.
