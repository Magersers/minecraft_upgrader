# Площадки и состояние публикации

Проверено 27 сентября 2026. Этот файл описывает подготовленный пакет; он не подтверждает появление страниц на сайтах.

## GitHub

Цель: `Magersers/minecraft_upgrader`, ветка `main`. Пользователь разрешил перенос актуального кода в main. Локальный git имеет отдельную историю: его нельзя отправлять поверх удалённой ветки с `--force`.

Перенос выполняется через текущую удалённую рабочую ветку и обычное слияние PR #1. Workflow выпуска теперь запускается из main. Проверить успешность Actions и наличие обоих JAR в `fabric-v0.6.4-alpha`; сверить контрольные суммы. Существующие теги/релизы не заменяются. Фактический результат публикации записывается отдельно в `PUBLICATION-STATUS.txt`.

Не менять видимость репозитория автоматически. Пока публичная доступность ссылок не подтверждена, не вставлять закрытые GitHub ссылки в публичную карточку CurseForge. Закрытая лицензия и приватность репозитория — разные настройки.

## CurseForge — готово к заполнению после входа автора

Создать аккаунт / войти: https://authors.curseforge.com/
Создание проекта: https://authors.curseforge.com/#/projects/create/choose-game

- Game: Minecraft Java Edition. Class: Mods.
- Name: Magersers' Upgrader. Проверить уникальность при создании проекта.
- Summary: `Risk spare items for better rewards with an inventory upgrade wheel and recipe-based item values.`
- Logo: `icon.png`, 1254×1254 PNG. Промо-иллюстрация создана с ИИ; это раскрыто в описании.
- Description: `description-en.md`, затем при желании `description-ru.md`.
- License: Custom, название `Magersers Proprietary License — All Rights Reserved`, полный текст `LICENSE`.
- Основная категория: выбрать подходящую категорию утилит/изменения игрового процесса из текущего списка формы. Не отмечать world generation или новые измерения.
- Две отдельные версии файлов: Minecraft 1.20.1 / Fabric и Minecraft 1.21.1 / Fabric. Обе Alpha.
- Required dependency: Fabric API, совместимая версия для конкретного Minecraft. Требования Loader/Java указаны в описании.
- Client and server: требуется на обеих сторонах. Одиночная игра поддерживается.
- Галерея: готовые файлы `screenshots/*.png` с подписями из `gallery.json`.
- Forge 0.3.0 не загружать как новый выпуск Fabric и не перелицензировать исторический JAR.
- Платные программы, выплаты и юридические соглашения владелец аккаунта оформляет самостоятельно.

Регистрация и аккаунт ещё не предоставлены. На модерацию ничего не отправлено.
