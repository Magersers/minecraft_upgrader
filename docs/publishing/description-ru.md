# Magersers’ Upgrader

Преврати лишние предметы в шанс получить более ценную награду. Выбери ставку из инвентаря, предмет и количество награды, посмотри вероятность и запусти рулетку.

**Ставка расходуется и при победе, и при поражении.** При успехе награда выдаётся после окончания прокрутки. Используются только игровые предметы: платных ставок и покупок нет.

## Возможности

- Кнопка со стрелкой в инвентаре игрока.
- Выбор ставки из инвентаря, поиск по названиям и каталог наград.
- Выбор количества получаемых предметов с пересчётом шанса.
- Рулетка со стрелкой, звуком и надписями о победе или поражении.
- Короткие цветные подсказки: мод, урон/броня, итоговая ценность.
- Стоимость обычного снаряжения и готовых товаров по рецептам. Кожа, чернила, урожай и еда оцениваются отдельно от дешёвого декора.
- Повышенная оценка поддержанного усиленного снаряжения и способностей; учёт заряда поддержанной энергетической брони.
- Снижение ставки за износ вплоть до 99% и дополнительный хард-режим для простых ресурсов.
- Проверка предметов, количества и выдачи награды на сервере.

## Установка

Minecraft **1.20.1**: Java 17+, Fabric Loader 0.17.2+, Fabric API 0.92.12+1.20.1. Minecraft **1.21.1**: Java 21+, Loader 0.17.2+, API 0.116.17+1.21.1. Используй JAR строго для своей версии Minecraft и установи одинаковую сборку на клиенте и сервере. Одиночная игра поддерживается.

Открой инвентарь и нажми кнопку со стрелкой. Выбери ставку, перейди в каталог наград, укажи цель и количество, проверь шанс и нажми «Улучшить».

Интерфейс преимущественно русский, названия предметов зависят от языка Minecraft. Версия имеет статус **alpha**.

## Моды и баланс

Поддерживаются доступные системе рецепты, атрибуты и теги предметов, а также источники добычи. Есть интеграционные проверки BetterX и TechReborn для Fabric 1.20.1. Полная совместимость со всеми модами и целиком со сборкой BMC2 не заявляется: нестандартные машины, данные предметов и скрытые эффекты могут требовать профиля датапака.

Для обычных рецептов: деревянный меч — 2.5 E, кожа — 48 E, бумага — 8 E, книга — 72 E. Моды с другими рецептами могут менять результат. `/upgrade audit` создаёт отчёт по ценам; `/upgrade hard true` включает дополнительное ограничение ставок простыми ресурсами.

Историческая Forge-сборка 1.20.1 сохранена отдельно, с прежними возможностями и лицензией. Fabric-файлы на Forge не работают.
